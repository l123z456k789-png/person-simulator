# 输入格式

## 正确示例

```text
[2024-05-01T09:30:00+08:00] A: 早，今天出门吗？
B: 看情况。
  如果不下雨就去。
[2024-05-01T09:32:00+08:00] A：那带上伞。
B: 好。
```

- `A:`、`A：` 都合法。
- 冒号后最多一个空格是格式分隔。
- 续行以两个空格开头；剥离两个结构空格后其余内容保留。
- 只由两个空格组成的续行表示正文空行。
- 空白行分隔消息，也可作为无时间数据的分组候选。
- 正文中形如 `A: ...` 的行必须缩进两个空格。

## 错误示例

```text
A: 你好
C: 我是第三人          # 错误：标签不是 A/B（或自定义的两人标签）
这是一行无归属文本      # 错误：没有消息头
A:                     # 错误：空正文（若没有有效续行）
B: 你好
```

错误会报告行号与原因，但不会把私人正文回显到错误消息中。

## 标签与 target

```bash
python -m person_simulator validate \
  --input examples/sample_chat.txt \
  --speaker-a 小明 --speaker-b 小红 \
  --target 小明
```

`--target` 必须与某个标签精确匹配；文件顺序不代表身份。
