# 测试说明

## 工程测试

`python -m pytest` 验证程序行为：解析、身份、切分、预算、配置、HTTP 适配、重试、证据校验、恢复、渲染、评估评分，以及模式 C 的运行时加载、邀请加密、会话限额、输出检查、双监听服务、跨邀请隔离和 CLI。

当前基线：180 passed（Windows，Python 3.12.10；新增评估覆盖、模板与标记测试后）。

工程测试通过只说明代码按契约工作，不说明生成的人物像本人。

## 模拟质量

人物模拟质量必须由真实材料、独立留出对话、独立评审回答来评估：

- `eval prepare` 生成评估包；
- 用户把人物材料上传到网页版 AI，逐题在新会话测试并人工填写回答；
- 至少一位了解原人物的评审按 1—5 分打分，并标记身份错误、编造历史、事实错误和无依据推断；
- `eval score` 只汇总已有评分，不自动生成“真实效果通过”。

Mock 生成的回答、合成评分和测试快照只能验证评分器计算，不能证明人物相似度。完整的数据格式、评分规则、人工步骤和局限见 [`docs/evaluation.md`](evaluation.md)。

## 禁止

- 删除测试、降低断言或伪造运行结果来制造通过。
- 把 `coverage=1` 当成模型已理解全部内容。
- 把 Mock 产物当成真实人物建模结果。
